# Преобразование выбранного неотрывного минора методом Гаусса к диагональному

## Формат входного файла

```text
m n
a11 a12 ... a1n
a21 a22 ... a2n
...
am1 am2 ... amn
row_start row_end
column_start column_end
```

Где:

- `m` — количество строк матрицы;
- `n` — количество столбцов матрицы;
- следующие `m` строк содержат по `n` чисел;
- `row_start row_end` — первая и последняя строки минора включительно;
- `column_start column_end` — первый и последний столбцы включительно;
- диапазоны должны иметь одинаковую длину, чтобы минор был квадратным;
- номера строк должны находиться в диапазоне от `1` до `m`;
- номера столбцов должны находиться в диапазоне от `1` до `n`;

## Запуск
Запуск с файлом `input.txt` и сохранением в `output.txt`:

```console
python main.py
```

Можно указать другие пути:

```console
python main.py input_2.txt --output result.txt
```
`output.txt` содержит только итоговую матрицу: по одной строке матрицы на строку
файла, элементы разделены пробелами.
